# Bakery-Analytics
## 📌 Project Overview
Bakery AnalyticsDashboard เป็นระบบ Interactive Data Visualization ที่พัฒนาขึ้นเพื่อวิเคราะห์ข้อมูลธุรกรรมร้านเบเกอรี่ โดยนำข้อมูลด้านยอดขาย กำไร ลูกค้า สินค้าคงเหลือ และช่องทางการชำระเงิน มานำเสนอในรูปแบบ Dashboard แบบ Interactive เพื่อช่วยให้ผู้ใช้งานสามารถวิเคราะห์ข้อมูลและสนับสนุนการตัดสินใจทางธุรกิจได้อย่างมีประสิทธิภาพ
โครงการนี้ดำเนินการตามแนวคิด CRISP-DM (Cross Industry Standard Process for Data Mining) ตั้งแต่ขั้นตอนการทำความเข้าใจข้อมูล การเตรียมข้อมูล การวิเคราะห์ข้อมูล การสร้าง Dashboard และการเผยแพร่ระบบผ่านเว็บไซต์
---
## 🎯 Objectives
- วิเคราะห์ยอดขายของร้านเบเกอรี่
- วิเคราะห์กำไรของแต่ละหมวดหมู่สินค้า
- ศึกษาพฤติกรรมการชำระเงินของลูกค้า
- วิเคราะห์สถานะสินค้าคงเหลือ
- วิเคราะห์ความเสี่ยงการหมดอายุของสินค้า
- พัฒนา Interactive Dashboard สำหรับการแสดงผลข้อมูล

## 📊 Dataset
Dataset ที่ใช้เป็นข้อมูลธุรกรรมร้านเบเกอรี่ ประกอบด้วยข้อมูลมากกว่า 16,000 รายการ และมากกว่า 40 คุณลักษณะ เช่น
- Transaction_ID
- Date
- Customer_Age
- Product
- Category
- Quantity
- Total_Bill
- Payment_Method
- Season
- Profit
- Waste_Cost
- Expiry_Risk
- Units_Produced
- Units_Sold
- Unsold_Units

## Prompt AI
1.ช่วยสร้าง Interactive Dashboard ด้วย HTML, CSS และ JavaScript
เงื่อนไข:
- ใช้ Chart.js
- อ่านข้อมูลจาก CSV
- มีกราฟอย่างน้อย 4 ประเภท
- มี Filter สำหรับเลือกข้อมูล
- รองรับ Responsive Design
- มี KPI Cards และ Quick Insight

ต้องการ:
- KPI Cards
- Modern UI
- Glassmorphism Design
- Hover Effects
- Responsive Layout
